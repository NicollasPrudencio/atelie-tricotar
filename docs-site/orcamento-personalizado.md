# Pedidos de orçamento personalizado

No site público existe um formulário **"Solicitar orçamento personalizado"**, pra quando uma
cliente quer encomendar algo sob medida que não está pronto na loja.

## O que acontece quando alguém envia

Hoje, ao enviar o formulário, o site manda um **e-mail** direto pra caixa de entrada do ateliê
com os dados preenchidos. Não existe nenhuma tela dentro do painel pra rever pedidos antigos —
o e-mail é a única forma de acompanhar. Se ele for apagado ou perdido, o pedido não fica
registrado em nenhum outro lugar.

> Isso é uma lacuna conhecida, não uma limitação definitiva — está registrada como tarefa
> pendente pra criar futuramente uma tela de acompanhamento desses pedidos dentro do painel.
